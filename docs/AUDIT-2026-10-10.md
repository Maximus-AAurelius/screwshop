# ScrewShop audit: 2026-10-10

Scope: the whole app, judged against what it's for. The three goals:

1. Make DJ Screw / Michael Watts mixes from two songs on two turntables.
2. Make beats on M-AUDIO: upload, split, pick sounds, put them on Oxygen pads, play, record and sequence.
3. Write and record.

Method: a read-only code review of every tab and the server, plus this round's builds and browser tests. Items marked *(code review)* were found by reading the code and were not reproduced in a browser.

## Bottom line

Most of the engine works and is well tested. The main problem was **discoverability**: the right path existed, but nothing walked you down it, and the docs still pointed at buttons that were gone. This round adds guided walkthroughs for the two main workflows, a video-to-MP3 import, and fixes for the silent failures below. The biggest remaining holes are in **beat making**:

- no way to audition sounds from inside M-AUDIO;
- no automatic drum chopping;
- no time-stretch;
- beat export covers only one pattern.

## Added this round

- **Walkthroughs** (`guide.js`, `guide-tours.js`, `guide.css`):
  - **SCREW MIX** (18 steps): load, slow, tape sound, record, run-backs, lag + flick, drag, scratch, record 2 on B, match tempo, cue on the beat, blend, save.
  - **BEAT FROM A SPLIT** (16 steps): upload, full split, open pack, load pads, MIDI, play, trim, tempo/click, record, play back, save, Studio/export.
  - **SEQUENCER BEAT** (10 steps): demo kit or yours, kick, snare, hats, loop, swing, variation, save.
  - How a step works: it lights up the real control and notices when you've done it. **SHOW ME** does the step with an on-screen cursor. **AUTO-PLAY** runs the whole tour, using demo audio if the library is empty.
  - Progress is remembered. Launch buttons sit at the top of the SCREW and M-AUDIO tabs, and the Trill GUIDE points to them.
  - Test: `tests/guide_browser.py` auto-plays all of SCREW MIX and SEQUENCER BEAT and steps through BEAT FROM A SPLIT.
- **VIDEO TO MP3** on SONGS (`scripts/media_import.py`, `POST /api/import-media`):
  - Direct media link or a video file → 320 kbps MP3 song.
  - Safety: refuses local and home-network addresses (re-checked on redirects), caps size at 300 MB and length at 30 minutes, and FFmpeg reads only the local file.
  - Gives a clear message for web-page links (YouTube etc.) and for videos with no audio.
  - Test: `tests/media_import_browser.py`.
- **Turntables** (earlier in this session):
  - Controller look, jog-wheel scratching (AudioWorklet), and per-deck SLOW (0.02–4 s, drag or stop).
  - −0.01…−0.08 speed pads, chop pads, flick/lag/cut, TAPE character, scrolling waveforms.
  - Tests: `tests/screw_tables_browser.py`, and `tests/runback_accuracy_browser.py` was hardened.

## Test status

The full suite was run on 2026-10-10 (38 files: Python unit tests, Node tests and Chromium browser suites, including the real Demucs split smoke test). Everything passes except one test:

- **`tests/oxygen_pad_mapping_browser.py` fails:** a MIDI note on the old saved pad map doesn't light pad 5 (`assert lit == [5]` gets `[]`).
  - It fails the same way on the original files from before this session's changes, so it is **pre-existing**. The cause hasn't been traced yet.
  - The failing check is in the sampler's note → pad routing. This matters for the real Oxygen, so look at it first among the beat-making fixes.

## Holes that still need filling (ranked)

### Beat making (goal 2): highest impact

1. **No sound browser inside M-AUDIO.** LOAD FROM SONGS switches tabs and stops the sampler, so you can't audition splits against a running loop. The old in-sampler library code is still there but never drawn, and its test expects it to stay hidden. *Build:* a slim drawer listing split packs and stems with ▶ preview and "→ selected pad".
2. **No auto-chop.**
   - Getting 16 drum hits onto pads needs a Full split. Even then you get only about 6 extracted drum hits and one phrase per stem *(code review: sound_library.py)*.
   - "Slice to pads" needs typed seconds.
   - *Build:* "Chop to 16 pads by beat/transient" in the editor and in the pack picker.
3. **No time-stretch or loop BPM detection.** Loops cut from songs drift against the sampler BPM, and pitch changes length. *Build:* detect a sound's BPM on load, plus a "fit to tempo" option.
4. **Export covers one pattern only.** Export WAV/MP3 renders the current pattern once, about 2.9 s for a 4-beat loop, with the tail cut. *Build:* a loop count, "all patterns in order", and a tail.
5. **Missing sequencer basics:**
   - clear pattern or lane;
   - copy a lane;
   - velocity painting;
   - note repeat (stubbed);
   - a pattern chain or song mode inside the sampler.

   Undo is per session.
6. **Saved beats have no audio preview** in SONGS until they're sent to Studio *(code review)*.
7. **Beat/kit library clutter** *(code review)*:
   - New Beat and Open beat auto-save the current project, which can pile up "Untitled beat" copies;
   - there's no Save As;
   - Save Kit always makes a new copy.

### Screw mixes (goal 1)

1. **BUILD VERSION renders only the live table.**
   - A two-song mix can be captured only with RECORD LIVE MIX.
   - Hook, DOUBLE UP and LAG need the same record on both tables.
   - *Build:* a "tape builder" that strings songs together with planned blends.
2. **LOAD ON BOTH TABLES only lists library songs.** A second song on B comes from deck B LOAD TRACK or SONGS → More → Load deck B. *Build:* a "Load on B" button next to the station's song list.
3. **No sync/beat-lock between two different songs** beyond matching speed by hand (pads, fader) and MATCH B→A.
4. Not tested: a real physical scratch feel and latency on this computer's audio device.

### Writing and recording (goal 3)

1. **Lyrics don't show in STUDIO while you record.** Notepad songs aren't linked to a beat or takes and can't be deleted *(code review)*.
2. **The mic uses Chrome's default voice processing** (echo cancellation, noise suppression, auto gain), which colours vocals. There's no input picker and no punch-in *(code review)*.
3. **The sampler stops when you leave M-AUDIO**, so you can't write in NOTEPAD over a looping sampler beat. The workaround is Send to Studio, then play it in Studio.

### Clarity

- **"Chop" means five things:**
  - the deck CHOP button (a loop);
  - SCREW chop pads;
  - "CHOP IT LIVE";
  - "Chop to pad";
  - the Chops category.

  Suggest renaming the deck button to LOOP and the SONGS action to "Cut to pad".
- **Duplicate transports** (global, station, per-deck) and **duplicate tempo controls** on SCREW. Similar save/send/export actions don't explain their differences.
- **Export WAV/MP3, New Beat and Update Studio render are hidden** in "Project, transfer & export", which exists only while the sequencer is open.
- **Computer-key shortcuts for the pads are never shown in the UI.**
- **Quick split vs Full split don't say what they produce.** The walkthrough explains it, but the buttons should too.
