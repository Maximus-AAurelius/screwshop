# ScrewShop audit — October 1, 2026

This audit runs against isolated local stores and generated audio. The owner's `data/` directory and existing songs, recordings, sampler sessions, and source audio are preserved. The canonical app remains `docs/barwork.html` with five tabs and the `/barwork` URL.

## Recording, arrangement, and service findings

Fixed the following confirmed issues:

- A locked Studio track could still accept dragged or imported clips. Both source and destination locks now apply, and an import rechecks the destination after decoding finishes. An import cannot alter a session while recording or loading is in progress.
- Removing an entire Studio track had no Undo checkpoint. Track deletion and imported audio now support Undo, including original source offsets. Audio source files remain intact.
- An interrupted pointer gesture committed an unfinished region edit. Pointer cancellation now restores the displayed and stored arrangement.
- Importing or moving a clip onto a new track saved the empty new track before saving its audio region. These compound edits now save one complete arrangement, preventing an incomplete intermediate session snapshot.
- Closing or reloading a browser during a successful local save could raise a Windows connection-aborted error and incorrectly log a failed save. JSON and file responses now tolerate disconnected browsers.
- The legacy deck browser regression still tried to click records to toggle playback after records acquired scratch gestures. The regression now exercises the separate deck playback controls.

Studio also releases its document click handler and region menu when disposed. Successful `addClip` calls now return the created clip so callers can report completed actions accurately.

## Library organization and sampler output

The SONGS page now browses the existing local records through one organized library: imported originals, saved versions, stems, recordings, editable sampler beats, kits and sound packs. It has category counts, search, sorting, grouped rows, editable names, preview transport, and direct Studio/deck/split/download actions. The existing storefront and Trill images remain in the app. No user audio was moved or reorganized on disk.

Library removal now removes only its listing and retains the source audio used by Studio regions and sampler assignments. Names save only after a successful local database response. Studio and sampler sound browsers now search by sound and folder/type, sort results, distinguish saved versions and recordings, and retain search focus, caret ranges and open groups through background refreshes. Group state is recorded immediately, including when someone closes a group and starts searching before its native toggle event arrives. Sorting stays inside sound folders, so editable beats without rendered audio cannot displace playable sounds at the top of the sampler browser. MIDI playback and live input processing were kept outside these browser redraws.

Fixed a confirmed output mismatch: Studio mix export previously ignored playback speed. The rendered duration, clip start positions and source playback rates now honor the selected Studio speed, so the exported pitch and timing match preview. Sampler audio actions report an addition only when Studio actually returns the created region. Sampler handoff now saves the completed arrangement after placing the rendered audio, without an intermediate empty-track snapshot.

## Shared interface, Screw workspace and rapid MIDI

All five tabs now share charcoal surfaces, clearer system typography, consistent borders and controls, compact headers, and an accessible active tab indicator. The original storefront, Trill, Purple Angel record art and drawn Oxygen keyboard remain. Desktop SCREW places the records and mixer beside the Screw Box so the records are reachable without scrolling through editing tools. Phone layouts retain their own scrolling areas and stacked controls. Extra scratch/pitch/save explanations are available in an expandable help section. The app shell cache and installed-app theme include the new styles and library files; API responses, credentials and audio remain excluded from the shell cache.

The shared transport now shows the stem session position and duration, allows seeking and looping, and keeps the playback clock/end state current while another tab is open. Entering an idle Screw workspace selects the transport for its current mode, so Play does not accidentally restart an unrelated Studio arrangement. Originals and editable sessions are retained when saving a new version.
